# Chief-kief

A simple CLI tool inspired by Chief Keef 🎤

## Description

Chief-kief is a fun command-line tool that brings Chief Keef's energy to your terminal. Get random quotes and phrases inspired by the legendary rapper.

## Usage

### Get a random quote (default behavior)
```bash
python3 chief_kief.py
```

### Get a random quote (explicit command)
```bash
python3 chief_kief.py quote
```

### Show help
```bash
python3 chief_kief.py help
```

## Installation

No external dependencies required! Just Python 3.

```bash
git clone https://github.com/s1dxes/Chief-kief.git
cd Chief-kief
python3 chief_kief.py
```

## Examples

```bash
$ python3 chief_kief.py
Bang Bang! 🔫

$ python3 chief_kief.py quote
Love no Thotties

$ python3 chief_kief.py help
Chief-kief: A Chief Keef inspired CLI tool

Usage:
  python chief_kief.py quote    - Get a random quote
  python chief_kief.py help     - Show this help message
```
